# 전라도편 이미지 넣는 곳

이 폴더(`assets/jeolla/`)에 **아래 이름 그대로** PNG를 넣으면 게임에 자동으로 나타납니다.
아직 없는 이미지는 CSS로 그린 비 오는 들판 / 점선 placeholder가 대신 나옵니다. (오류 안 남)

## 1. 배경 (10구간) — 필수
화면 1000×640 기준. 더 크게(예: 1600×1024) 그려도 `cover`로 맞춰집니다.

| 파일명 | 구간 | 시각 | 날씨 |
|---|---|---|---|
| `01_서해안갯벌.png` | 서해안 갯벌 | 06:00 | 흐림 |
| `02_해안도로.png` | 해안 도로 | 07:00 | 약한 비, 물웅덩이 |
| `03_평야마을.png` | 평야 마을 | 08:00 | 비 |
| `04_논밭길.png` | 논밭 길 | 09:00 | 강한 비 |
| `05_하천다리.png` | 하천 다리 | 10:00 | 집중호우, 흙탕물 |
| `06_침수도로.png` | 침수 도로 | 11:00 | 집중호우 + 천둥 |
| `07_내륙마을.png` | 내륙 마을 | 12:00 | 강한 비, 마당까지 침수 |
| `08_상류계곡.png` | 상류 계곡 | 13:00 | 비 잦아듦 |

> 지면 높이: 캐릭터 발 높이는 화면 위에서 약 498~516px입니다.
> **물이 차오르는 효과는 게임이 화면 아래쪽에 반투명 물 레이어로 자동으로 그립니다.**
> 배경에는 물을 그리지 말고 마른 상태로 그려 주세요. (구간마다 물 높이가 0→47px로 올라갑니다)
